01

Setup

Three components: your own Discord app, the local host, and the app ID here in settings.
  1. 1

    Create a Discord app

    Open

    Create a new application in the Discord Developer Portal. Its name will appear in your profile – for example, “Playing Chrome” if you name the app Chrome.

    Step-by-step guide
    1. Click New Application and choose a name.
    2. Under General Information, copy the Application ID.
    3. Optional: Under Rich Presence → Art Assets, upload assets/discord-asset.png as chrome.
    4. Paste the ID into the Application ID field below.
  2. 2

    Install the local host

    Open

    The host is the bridge between Chrome and Discord. It runs only on your computer and talks directly to the local Discord client.

    ./host/install.sh

    Linux or macOS, Node.js 18+. Then reload the extension at chrome://extensions. The script adds the extension ID automatically.

    …

    The executable host/run-host.sh is generated by the installer. It must be executable.

  3. 3

    Enable sharing in Discord

    Open

    The Discord desktop app must be running. Also check under Settings → Activity Privacy that Discord is allowed to share activities. Discord in the browser does not support local Rich Presence.

    Your activity will be visible to friends as long as your Discord status is not set to “Invisible”.

All set. Your browser activity is now being sent to Discord locally.

04

Privacy

You decide which sites never appear in Discord.

One domain per line. Subdomains are included automatically. No presence is shown for these sites.

  • Local: The extension reads the active tab. The host only receives the finished activity.
  • To Discord: only the visible lines and – if enabled – elapsed time and images.
  • No developer server: no telemetry, analytics, or accounts.
  • Not stored: The host keeps only the latest activity in memory.
  • Settings: stored in Chrome Sync if you use Chrome Sync.
  • Website icons: Enabled by default and loaded through Google; turn them off to keep domains from Google.
Permissions: tabs for title and URL, storage for settings, idle for idle detection, nativeMessaging for the local host, and alarms as a keep-alive. There are no content scripts and no access to page content.

05

About

What happens under the hood – and where the limits are.

How it works

Chrome reports the active tab to the extension. It builds a Discord activity from it and sends it via Native Messaging to the local Node host. The host connects directly to the desktop app through the Discord IPC socket. Nothing goes through the internet.

Limitations

Requires the Discord desktop app (not the web version) and Node.js for the host. Flatpak or Snap sandboxes may block the IPC socket. On Windows, the host has to be packaged as an executable.

App name in Discord

Discord shows the name of the developer application, not the extension. Name your app Chrome, for example, so Discord displays “Playing Chrome”.

Uninstall

Remove the extension, then run ./host/install.sh --uninstall. This removes the native host manifests from the detected browser folders.
